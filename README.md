# 木序 WOODWEAVE — Atelier 05 精修版

[開啟 3D 互動展示](https://rolanthhuang.github.io/WOODWEAVE/) · [本輪驗證紀錄](TEST_REPORT.md) · [前版 1,080 間紀錄](ATELIER04_TEST_REPORT.md)

九層斜向堆疊的木質多面體建築，中段房間最多、上下收窄。Atelier 05 將重點放在近看的木紋、Wool felt、木作接合、立體縫邊、垂墜織物與專屬裝置，保留科技極簡風與四／五／六面體房間。

**本版初始與同時顯示上限為 540 間**，可在 36–540 間之間向外生長；九層分布為 **12 / 30 / 60 / 96 / 132 / 96 / 60 / 36 / 18**。每房都有不同家具構成與專屬裝置。原有 1,080 種房間設計的生成規則及逐房精修檢查保留在程式中，介面的同時顯示上限則降低，優先保留近看精緻度與互動流暢性。

1,080 間精修場景在多輪高解析度測試中表現不一致，其中一次近景平均降至 36.1 FPS，因此沒有沿用單次通過結果作為發布依據。本版 540 間使用同一套精修材質與幾何；540 是本輪選定的展示上限，不代表所有硬體的理論容量。[詳見本輪測試、未通過紀錄與使用範圍](TEST_REPORT.md)。

## 操作

- 拖曳旋轉；滾輪或加減鍵縮放；右鍵或 Shift 拖曳平移。單指旋轉，雙指縮放／平移。
- 選擇建築外觀、打開剖面或支撐骨架；點樓層分布圖可單獨觀看一層，顯示全部恢復九層。
- 調整「樓層展開」拆開整體。展開時隱藏連續骨架，屬於拆解示意。
- 輸入 1–540 房號直達，再按「走進這個房間」；亦可點模型或使用前後房間箭頭。
- 單房可按「近看家具與材質」或專屬裝置的「近看」。裝置聚焦會移開遮擋的牆面；恢復全房會重新顯示。四面體的斜牆使用斜面判斷，避免高處近看被擋住。
- 細節面板提供自動、極致、輕盈三種品質，以及完整流暢度測試。預設極致、最高 2× 螢幕像素倍率。
- 支援俯瞰、正面、軸測、自動環繞、日夜與圖片匯出。Home 返回全景，Escape 返回聚落。
- 窄視窗以「調整聚落」開啟控制，房間資訊可收合。

## 材質與細節

- **木材**：2048 × 2048 色彩、法線與粗糙度貼圖；端面木紋為 1024 × 1024。圓角木家具、實際地板接縫、端面、嵌條、接頭、五金與細槽。
- **Wool felt**：2048 × 2048 色彩、法線與粗糙度貼圖，加上柔和掠射光；用於沙發、靠枕、椅墊與地毯。縫邊使用繩狀幾何，另有針腳、短纖維與流蘇。披毯使用垂墜網格與平滑法線。
- **木纖維與織布**：吸音木纖維板、細織布各有 1024 × 1024 材質組；床單、木纖維板與羊毛氈使用不同表現。
- **近看幾何**：圓角由 5 段增加至 9 段，器皿 64 段，球體／環體增加細分。設計庫逐房檢查，最多約 20.8 萬三角形；每房 2,494–3,224 段纖維、縫線或刻紋。
- **特色裝置**：九個家族各有不同的構成、排列、角度、數量、波形及刻紋。精修雕刻輪廓由每房種子決定，增加加工、層壓、端面、鑲釘或機械套環等對應細節。近看銘牌為 1024 × 320，含房號、特色名稱與樓層。
- **八種生活配置**：起居、睡眠、工作、閱讀、餐敘、冥想、創作及交誼；包括分塊軟墊、床組層次、書脊、茶具、數位螢幕、鍵盤、桌燈與葉片植栽。

這些是以固定種子生成的獨立設計，部分房間共享用途與裝置家族；並非手工繪製 1,080 套不同設計家族。檢查排除銘牌編號，比對實際家具與裝置的幾何、變換與顏色。原有房間在增建後仍保留其配置。

所有紋理在裝置本機生成，無外部材質下載；是程序化材料表現，並非實測材料掃描。材質的色彩使用 sRGB，法線及粗糙度使用非色彩資料。

## 流暢度策略與檢查

遠景共用材質，拉近切換精修材質；走進房間後使用精修幾何。本版使用樓層實例批次，減少高解析度下的繪製呼叫；原始碼對較大的生成場景保留空間分區路徑。單房最近使用快取最多 8 間，移除時釋放專用幾何及銘牌。閒置時停止連續繪圖。

內建約五分鐘測試涵蓋全景、60 秒近景、60 秒快速旋轉／大幅縮放、剖面、材質近看、沙發與織物、稜晶裝置、30 秒單房快速微距及換房／360–540 間重建。所有鏡頭測試固定極致品質，所有縮放過程納入計時。門檻為平均至少 45 FPS、P99 不超過 28 ms、沒有 >50 ms 畫格及顯示中斷；重建停頓另列。

[完整數值、裝置與測試限制](TEST_REPORT.md)。單一裝置的短時間測試不代表全裝置、長時間溫度、電池或記憶體上限保證。

## 支撐構想與驗證界線

設計中加入 **兩根側向巨柱**，各自落在基座上，並用最寬樓層附近的深桁架連接中央核心。逐層梁系、外側連續斜肋及中央核心，呈現由樓層向地面的荷載傳遞構想。表面保留木材語彙，轉換桁架與拉桿採木包覆／鋼構混合概念。

這是可視化的結構概念，**尚未進行承載驗算**。模型不是有限元素、剛體力學或施工設計；連接的幾何、九層分布與兩根側柱的存在可以檢查，但不能據此聲稱兩柱已足以承受自重、使用荷載、風力、地震、扭轉、撓度或接頭作用。梁柱、接點及基礎尺寸仍需依材料、跨度、地質與所在地法規由結構設計決定。

構想依據是連續荷載路徑：

- [FEMA／PNNL：從屋頂到基礎的連續荷載路徑](https://basc.pnnl.gov/resource-guides/continuous-load-path-provided-connections-roof-through-wall-foundation)
- [WoodWorks：CLT 懸挑及點支承系統的彎曲、剪力與支承考量](https://www.woodworks.org/resources/design-strategies-for-two-way-spanning-cross-laminated-timber/)

## 檔案與幾何

所有執行資源均在 `dist/`，沒有外部字型、分析追蹤、帳號或 API 依賴。根目錄 `index.html` 是可直接開啟的自含式展示頁，適合 GitHub Pages。可編輯模組保存在 `dist/`；以靜態網頁伺服器開啟 `dist/index.html`，或使用合併的 `dist/standalone.html`。近看材質在 `dist/craft.js`，各房精修幾何在 `dist/model.js` 與 `dist/furnishings.js`。單檔合併與檢查可分別執行 `node build-standalone.mjs`、`node verify.mjs`。Three.js r170 採 MIT 授權，授權檔位於 `dist/vendor/THREE-LICENSE.txt`。

四面體是三角錐，五面體是三角柱，六面體是菱形柱。相鄰兩個三角網格可合成菱形房間。房間細部分板及窗框不另計為主多面體面數。面積是幾何底面面積。各房間以固定種子產生用途、材質、色彩、家具尺度與位置；增建不會重設既有房間的配置。
